# 100句默写

看到中文，快速敲出英文。纯 HTML / CSS / JavaScript，无后端、无构建步骤、无运行时依赖。

题库目前只有 6 句原创示例，没有收入任何出版物原文。正式题库可在浏览器右上角设置中导入；导入内容只留在当前浏览器，不会提交到仓库或上传。GitHub Pages 页面及其静态文件可能公开可访问，即使源仓库为私有，因此出版物题库应使用本机导入。

## 使用

- 输入英文，按 **Enter** 核对；再按 **Enter** 进入下一句。**Shift + Enter** 换行。
- **Alt + H** 给提示，再按一次显示完整答案。提示使用状态会保留到刷新后。
- 忽略大小写、标点和多余空格；仅接受题库 `answers` 中明确列出的答案，不进行 AI 或语义判分。
- 掌握需要连续两次独立答对。答错或使用提示会把连续次数归零；弱句优先回来，通常隔开至少两道其他题再考。最后只剩弱句时，用已掌握的句子作为间隔。题库只有 1 / 2 句时，间隔分别缩短为 0 / 1 句。
- 今日默写统计不同句子的数量，旁边显示核对次数；掌握数累计保留。
- 全部掌握后可再巩固一轮；巩固答错的句子重新进入待掌握队列。
- 当前题目、输入、提示、已提交结果和进度自动保存在本地。浏览器清除数据会丢失记录，不同设备或浏览器不会自动同步。

## 题库格式

题库与代码分开，位于 `sentences.json`。可以直接替换该文件，或在设置中选择「导入题库 / 备份」。本机导入的题库优先于内置文件。

```json
{
  "version": 1,
  "title": "我的题库",
  "sentences": [
    {
      "id": "my-001",
      "chinese": "午饭后，我通常沿着河边散步。",
      "answers": [
        "I usually take a walk along the river after lunch.",
        "After lunch, I usually take a walk along the river."
      ],
      "hint": "take a walk / after lunch"
    }
  ]
}
```

`id` 应唯一且稳定；`hint` 可省略。也支持直接传入句子数组。文件上限 2 MB、1–1000 句、每句最多 20 个答案。换题库时，仅 id、中文与答案数组完全相同的句子保留已有进度。

「导出进度备份」下载一个含题库与进度的 JSON 文件。换设备后用同一个导入入口恢复。「重置学习进度」仅重置本工具的进度，保留题库，并要求确认。

## 本地运行与验证

通过 HTTP 打开，不要直接双击 HTML（浏览器会限制读取 JSON 文件）：

```sh
python3 -m http.server 8765
```

访问 `http://localhost:8765`。逻辑测试不需要安装依赖：

```sh
node --test tests/core.test.mjs
```

`tests/browser.test.mjs` 使用 Playwright 验证键盘流程、回炉、掌握、存储、导入导出和手机布局；Playwright 仅为测试依赖，网站运行不需要它。

## GitHub Pages

发布根目录到 Pages，使用 `main` 分支、`/ (root)`。`.nojekyll` 禁用 Jekyll，无需前端构建。私有仓库的 Pages 资格取决于 GitHub 套餐；未经确认不改变仓库可见性。
