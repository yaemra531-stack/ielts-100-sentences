# 100句默写

看到中文，快速敲出英文。纯 HTML / CSS / JavaScript，无后端、无构建步骤、无运行时依赖。

题库目前只有 6 句原创示例，没有收入任何出版物原文。正式题库可在浏览器右上角设置中导入；导入内容只留在当前浏览器，不会提交到仓库或上传。GitHub Pages 页面及其静态文件可能公开可访问，即使源仓库为私有，因此出版物题库应使用本机导入。

## 使用

- 右上角月亮 / 太阳切换夜间与日间模式，选择会在本机记住；首次跟随系统外观。两个页面在首次显示前读取主题，切换页面时保持夜间背景，无需等待练习脚本加载。
- 核对时有轻提示音：答对为两声上行短音，未匹配为低声下降短音，空白提交为单声轻点；答对图标有 0.34 秒短动画，不影响立刻进入下一句。右上角设置可关闭反馈效果并分别试听，选择保存在本机；刷新或查看历史不会重播。声音在浏览器本地生成，无音频下载；系统减少动态效果时不播放动画。
- 核对后自动朗读显示的参考英文一次（包括未匹配与空白提交），不会朗读错误输入；答案下方可重听，**Alt + R** 重听 / 停止。进入重写或下一句时停止；核对前不朗读，刷新已提交结果不重播。设置中可单独关闭自动朗读，手动重听仍可用，朗读不产生额外作答或掌握计数。
- 支持设置中导入本机语音包（30 MB以内的JSON），优先播放与英文原文对应的MP3；缺少录音时使用浏览器英文语音，优先英式女声，但可用音色由设备提供。包格式为 `{format:"ielts100-audio",version:1,voice:"音色名称",entries:[{text:"英文原文",mime:"audio/mpeg",base64:"MP3的Base64"}]}`。语音包仅保存浏览器IndexedDB，不上传，不写入进度JSON备份；换设备需重新导入。浏览器清理网站数据会丢失语音包；重置学习进度保留语音包。
- 第一遍按题库原顺序完成所有句子，然后优先复习未掌握的句子。
- 输入英文，按 **Enter** 核对；答对后再按 **Enter** 进入下一句；答错时按 **Enter** 重写本句，隐藏答案并清空输入，写对才能继续。**Shift + Enter** 换行。
- **Alt + H** 给提示，再按一次显示完整答案。提示使用状态会保留到刷新后。
- 忽略大小写、标点和多余空格；仅接受题库 `answers` 中明确列出的答案，不进行 AI 或语义判分。
- 掌握需要连续两次独立答对。答错或使用提示会把连续次数归零；弱句优先回来，通常隔开至少两道其他题再考。最后只剩弱句时，用已掌握的句子作为间隔。题库只有 1 / 2 句时，间隔分别缩短为 0 / 1 句。
- 刚看过答案后的即时重写只算订正，不计独立答对，也不会缩短回炉间隔。先前作答可在核对后折叠查看（每句当前练习保留最近 20 次），重写输入时隐藏，避免照抄；换到下一句后清除本句临时作答区；页面底部的长期作答记录仍会保留。
- 页面底部按时间保存每次核对：原答案、题库答案、文字差异、题号、作答方式和时间（含时区）。正确、未匹配、即时订正、用过提示都会保留；可筛选未匹配记录，一键导出 Markdown 给 AI。备份 JSON 也包含记录。判分仅匹配标准文本，未匹配不代表语法或意思错误；导出文件会明确说明。
- 升级时恢复旧版仍保留的当前答案与临时历史，标为时间未知；旧版已经清除的答案无法补回。重置学习进度会清空全部作答记录，换题库则保留记录中的原题目快照。
- 今日默写统计不同句子的数量，旁边显示核对次数；掌握数累计保留。
- 全部掌握后可再巩固一轮；巩固答错的句子重新进入待掌握队列。
- 当前题目、输入、提示、订正状态、当前句先前作答、已提交结果和进度自动保存在本地。浏览器清除数据会丢失记录，不同设备或浏览器不会自动同步。

## 题库格式

题库与代码分开，位于 `sentences.json`。可以直接替换该文件，或在设置中选择「导入题库 / 备份」。本机导入的题库优先于内置文件。

```json
{
  "version": 1,
  "title": "我的题库",
  "sentences": [
    {
      "id": "my-001",
      "chinese": "午饭后，我通常沿着河边散步。",
      "answers": [
        "I usually take a walk along the river after lunch.",
        "After lunch, I usually take a walk along the river."
      ],
      "hint": "take a walk / after lunch"
    }
  ]
}
```

`id` 应唯一且稳定；`hint` 可省略。也支持直接传入句子数组。文件上限 20 MB、1–1000 句、每句最多 20 个答案。换题库时，仅 id、中文与答案数组完全相同的句子保留已有进度。

「导出进度备份」下载一个含题库与进度的 JSON 文件。换设备后用同一个导入入口恢复。「重置学习进度」仅重置本工具的进度，保留题库，并要求确认。

## 词伙页

从首页右上角「词伙」进入 `chunks.html`。浏览模式按原句序显示英文词伙、中文释义、完整原句与易错点，方向键切换句子；默写模式只显示中文释义和中文语境，核对后才显示英文与语法提醒。Enter 核对、隐藏答案重写、下一词伙。判分忽略大小写和标点，冠词、时态、单复数须匹配原词伙；同义表达不由程序判定。

对错按词伙分别累计，订正另标；一轮后可重练全部或只练错过的。浏览位置、输入、核对结果、逐次作答记录自动保存。底部折叠记录可按对错筛选、导出备份；设置中可导入题库/备份、仅重置词伙记录。当前词伙及相同英文词伙的旧答案在默写前隐藏。

浏览模式可点击词伙旁的播放按钮；完整原句单独手动播放。默写核对后自动读标准词伙一次，核对前不读；**Alt + R** 重听 / 停止，重写、下一项、切换模式或离开页面立即停声。设置中可关闭自动读，手动重听仍可用；朗读不改变判分或作答记录。

浏览快捷键：**← / →** 切换句子，**1–4** 按按钮编号朗读对应词伙（导入更多词伙时支持到8），**0 / 空格** 朗读原句，**Esc** 停止；同一播放键再按一次可停止。输入框、句序选择框与设置中不触发这些快捷键；空格在聚焦按钮时保留按钮自身的操作，可用0播放原句。浏览朗读不增加作答记录。

词伙录音在设置中单独导入，格式为 `{format:"ielts100-chunk-audio",version:1,voice:"音色名称",entries:[{text:"词伙原文",mime:"audio/mpeg",base64:"MP3的Base64"}]}`，上限30 MB。使用 IndexedDB `ielts100.audio.v1` 的 `chunks` 键保存；整句播放复用原有 `current` 键，两个语音包互不覆盖。缺少录音时使用浏览器英文语音。语音包不包含在进度备份中，换浏览器或设备需要重新导入。

词伙页使用独立的本地存储键 `ielts100.chunks.bank.v1` / `ielts100.chunks.progress.v1`，不修改整句题库、进度和语音包；夜间模式与整句页共用偏好。公开 `chunks-example.json` 只有 6 句原创示例。正式词伙题库通过设置本机导入，不进入仓库；换浏览器或设备需导入本机题库/词伙备份。

词伙题库格式：

```json
{
  "format":"ielts100-chunks", "version":1, "title":"我的词伙题库",
  "sentences":[{
    "id":"my-001", "number":1,
    "chinese":"午饭后，我通常沿着河边散步。",
    "english":"I usually take a walk along the river after lunch.",
    "chunks":[{
      "id":"my-001-c01", "english":"take a walk", "meaning":"散步",
      "source":"hint",
      "notes":[{"text":"冠词 a 不漏。", "focus":["a walk"]}]
    }], "notes":[]
  }]
}
```

`source` 取 `hint`（原词伙提示）或 `supplement`（补充，页面会标明）；`meaningEdited:true` 标明释义校对。英文词伙必须是完整原句的原样子串，编号、ID 不重复。`notes` 为可选易错点；`focus` 必须原样出现在完整英文原句中。全句的提醒放在句子层的 `notes`。词伙备份格式为 `ielts100-chunks-backup`，包含题库及自己的进度。

验证：`node --test tests/chunks-core.test.mjs`；`tests/chunks.browser.mjs` 验证浏览、无提示默写、订正、整轮、独立存储、备份与手机视口。可通过本机环境变量 `CHUNKS_FILE` 传入私人词伙题库进行整轮验证，不作为公开测试夹具。

`tests/chunks-audio.browser.mjs` 验证朗读触发、停声、开关、重听和刷新不重播；传入本机 `CHUNKS_FILE` / `CHUNK_AUDIO_PACK` / `AUDIO_PACK` 可验证真实词伙MP3播放、语音包保留及整句录音不被覆盖。`TEST_URL` 可切换到部署网址验证。

`tests/theme-browse.browser.mjs` 验证练习脚本未加载时的首屏主题、浏览朗读快捷键、输入和设置中的按键保护、日夜切换与移动布局。

## 本地运行与验证

通过 HTTP 打开，不要直接双击 HTML（浏览器会限制读取 JSON 文件）：

```sh
python3 -m http.server 8765
```

访问 `http://localhost:8765`。逻辑测试不需要安装依赖：

```sh
node --test tests/core.test.mjs
```

`tests/browser.test.mjs` 使用 Playwright 验证键盘流程、回炉、掌握、存储、导入导出和手机布局；Playwright 仅为测试依赖，网站运行不需要它。
`tests/feedback.browser.mjs` 另行验证真实 Web Audio 节点、三种触发、静音保存、试听不改进度、减少动态效果，以及音频不可用时仍能继续练习。
`tests/narration.browser.mjs` 验证朗读触发与停止、开关及键盘重听；传入本机 `AUDIO_PACK` / `BANK_FILE` 可额外验证真实 MP3 播放与语音包刷新保存。正式题库及语音包不进入公开仓库。

## GitHub Pages

发布根目录到 Pages，使用 `main` 分支、`/ (root)`。`.nojekyll` 禁用 Jekyll，无需前端构建。私有仓库的 Pages 资格取决于 GitHub 套餐；未经确认不改变仓库可见性。
